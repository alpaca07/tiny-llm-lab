# Step 6 실습 가이드 — 심화

관심 가는 주제부터 골라서 해도 된다. 각 항목은 독립적이다.

## 6-1. 학습 효율
- **mixed precision** (bf16/fp16): 속도·메모리 변화 측정
- **gradient accumulation**: 작은 GPU에서 큰 배치 효과 내기
- **FlashAttention**: `F.scaled_dot_product_attention`으로 직접 구현 어텐션을 교체하고 속도/메모리 비교
- **`torch.compile`**: 켰을 때 step 시간 변화
- 기록할 것: step당 시간, 최대 메모리, 최종 loss가 그대로인지

## 6-2. 정렬 (alignment)
- **DPO**: (프롬프트, 선호 답변, 비선호 답변) 쌍 데이터로 학습
- 직접 소규모 선호 데이터셋을 만들어 적용 → 전후 응답 비교
- 이해할 것: 보상 모델 없이 선호를 바로 반영하는 구조, 기준(reference) 모델과의 KL 균형

## 6-3. 양자화
- 학습된 모델의 가중치를 **int8**로 변환해 크기·속도·loss 변화 측정
- 레이어별로 민감도가 다른지(예: 임베딩, 출력층) 실험

## 6-4. 서빙
- 학습한 모델을 간단한 API 서버로 감싸기 (생성 엔드포인트)
- 스트리밍 출력, 동시 요청 처리 시 지연 시간 확인
- (선택) 모델 파일을 외부에 공개할 때 보안 점검: 입력 길이 제한, 요청 횟수 제한

## 6-5. (선택) 보안 연결
- 직접 학습한 작은 모델에 **데이터 포이즈닝/백도어**를 심고 탐지해보기
- **멤버십 추론**: 특정 문장이 학습 데이터에 있었는지 loss로 구분되는지 확인
- 학습 데이터·파이프라인을 모두 통제할 수 있어서 공격 전후 비교가 깔끔하다
