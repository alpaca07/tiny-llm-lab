# Step 3 실습 가이드 — 사전학습 → 파인튜닝 → 명령어 튜닝

## 배울 것
- LLM이 만들어지는 전체 파이프라인을 작은 규모로 한 바퀴 돌려보기
- 제대로 된 학습 루프에 필요한 요소들

## 단계
### A. 사전학습 (pretraining)
- 더 큰 텍스트 코퍼스에서 다음 토큰 예측으로 학습 (Step 2의 BPE 사용)
- 학습 루프 업그레이드
  - **학습률 스케줄**: warmup → cosine decay
  - **weight decay** (AdamW), **gradient clipping**
  - **체크포인트 저장/불러오기** (`*.pt`는 gitignore됨)
  - 주기적 평가 loss와 **perplexity** (`exp(loss)`) 기록
- 학습 곡선(loss vs step)을 그래프로 저장

### B. 생성 품질 올리기
- **temperature**, **top-k**, **top-p** 샘플링 구현
- 같은 프롬프트로 설정별 결과 비교

### C. 파인튜닝
- 작은 특정 도메인 텍스트(예: 특정 작가 글)로 이어서 학습
- 사전학습 모델 vs 파인튜닝 모델의 출력 스타일 비교
- 학습률을 사전학습보다 작게 잡는 이유 확인

### D. 명령어 튜닝 (instruction tuning)
- `질문 → 답변` 형식 데이터를 템플릿으로 변환 (예: `### Instruction ... ### Response ...`)
- **손실을 답변 부분에만 적용** (프롬프트 부분은 마스킹)
- 튜닝 전/후 같은 질문에 대한 반응 비교

## 확인할 것
- 학습률 warmup이 없을 때 초반 loss가 불안정한지
- 체크포인트에서 이어서 학습했을 때 loss 곡선이 끊기지 않는지
- 작은 모델은 명령어를 "이해"하기보다 **형식을 흉내** 내는 수준이라는 점

## 셀프 체크
1. 사전학습과 파인튜닝은 목적함수가 다른가? (같은데 데이터만 다르다)
2. 명령어 튜닝에서 프롬프트 부분을 마스킹하는 이유는?
3. perplexity 10의 의미는? (모델이 평균 10개 후보 중에서 고민하는 정도)
