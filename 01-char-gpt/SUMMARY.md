# Step 1 요약 — 문자 단위 GPT (2026-11-09)

## 핵심 개념
1. **언어모델** = 앞 토큰들이 주어졌을 때 **다음 토큰의 확률분포**를 내놓는 함수. 글쓰기는 하나 뽑아 붙이고 반복하는 것.
2. **학습 데이터** = 입력 `x`와 한 칸 민 정답 `y`. 조각 하나에서 예측 문제가 `block_size`개 생김.
3. **loss** = 정답 확률 p에 대한 `−log p`. 기준선 `ln 65 ≈ 4.17`(그냥 찍기). 시작이 4.7인 건 랜덤 초기화 때문.
4. **바이그램** = 직전 글자 1개만 봄 → 철자 조각만 생성, loss 약 2.49에서 정체.
5. **셀프 어텐션** = 각 토큰이 Query로 질문하고, 잘 맞는 Key를 가진 토큰의 Value를 더 많이 가져옴.
   `softmax(Q·Kᵀ/√d + 마스크) · V`
6. **마스크** = 미래 토큰을 못 보게 가림. 없으면 정답을 베껴서 loss만 떨어지고 생성은 실패.
7. **위치 임베딩** = 어텐션은 순서를 모르므로 "몇 번째 자리인지"를 더해줌.
8. **멀티헤드** = 여러 관점으로 병렬 어텐션 후 합침.
9. **블록** = 어텐션(**통신**: 토큰끼리 정보 교환) → FFN(**계산**: 토큰별 처리). 각각 잔차 연결 + LayerNorm.
10. **잔차 연결** `x = x + f(x)` = 원본에 수정분을 **더해서** 신호가 층을 건너뛰는 지름길을 만듦. 깊게 쌓아도 학습됨.
11. **온도** = logits를 나눠서 분포 모양 조절. 낮으면 안전·반복, 높으면 다양·엉뚱.

## 직접 확인한 결과 (Colab T4, 3000 step 또는 600 step)
| 실험 | val loss | 의미 |
|------|---------|------|
| 바이그램 | 2.49 | 직전 글자만 봄 |
| 미니 GPT | **1.75** | 어텐션 효과, 대사 형식·실제 단어 등장 |
| 마스크 제거 (600) | 0.04 | 정답 베끼기, 생성은 망가짐 |
| 위치 임베딩 제거 (600) | 2.22 (기준 2.03) | 순서 정보 손실로 조금 나빠짐 |

## 헷갈렸던 것
- 마스크가 없으면 **뒤의 글자를 볼 수 있다** (못 보는 게 아니라). 마스크가 뒤를 막는 것.
- **FFN = 계산**, 위치 정보는 위치 임베딩 담당.
- 잔차 연결은 덮어쓰기가 아니라 **더하기**.

## 한 줄 정리
**GPT = 토큰 임베딩 + 위치 임베딩 → [어텐션(통신) → FFN(계산)] × N층 → 다음 글자 확률.**
